## 各阶段详细目标

### Phase 1：环境搭建与模型验证（收尾中）

- [x] OpenVINO 2025.4.1 环境搭建
- [x] PaddleOCR-VL 0.9B OpenVINO 推理跑通
- [ ] 准备 10 张测试图片（纯文字 ×3、表格 ×3、公式 ×2、图文混排 ×2）
- [ ] PyTorch vs OpenVINO 推理速度 Benchmark
- [ ] Tesseract vs PaddleOCR-VL 解析质量对比截图

### Phase 2：文档解析与切片模块

- [ ] PDF 可读性判断（pdfplumber 提取 → 判断是否走 OCR 路径）
- [ ] PaddleOCR-VL 逐页解析，输出结构化 Markdown
- [ ] 表格感知切片（表格行+表头为 chunk，段落按语义切分 300-500 字符）
- [ ] 元数据附加（doc_name, page, section_title）
- [ ] 3 份测试文档全流程验证

### Phase 3：RAG 问答链路

- [ ] BGE-small 模型转 OpenVINO 格式 + chunk 批量 embedding
- [ ] ChromaDB 入库（带元数据）
- [ ] Query embedding → Top-K 检索
- [ ] Qwen2.5-7B INT4 量化 + OpenVINO GenAI 推理
- [ ] Prompt 模板设计 + 输出带引用的回答
- [ ] 端到端延迟 Benchmark

### Phase 4：对比评测与优化

- [ ] Tesseract 方案 vs PaddleOCR-VL 方案全链路对比
- [ ] 对比维度：文字识别准确率、表格结构保留、问答正确率、解析耗时
- [ ] Gradio 界面（可选）

### Phase 5：整理提交

- [ ] Jupyter Notebook 整理（含对比演示）
- [ ] README.md + requirements.txt
- [ ] 测试文档样例
- [ ] 干净环境可复现验证
