项目简介：

小伴是一个陪伴式学习机器人，采用文心大模型 v2 API（IAM 认证）构建 Agent 决策链路。每次用户交互调用 3 次文心 API：意图理解（t=0.1）→ 任务规划（t=0.3）→ 对话执行（t=0.7），结合 FSRS 记忆调度算法和跨会话用户画像实现个性化教学。

已验证 3 组指令稳定通过：
- "开始今天的英语练习" → intent=practice
- "帮我复习上次的错误" → intent=review
- "总结我这周的学习情况" → intent=summary

阶段 2 计划将 Agent 大脑部署到 RDK X3，接入端侧 STT/TTS（hobot_asr/hobot_tts）和摄像头表情感知，实现具身交互。
